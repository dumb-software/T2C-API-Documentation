## Présentation

Les **XML T2C** contenaient toutes les dernières informations du réseau T2C.

Cela comprenait les Alertes, les Brèves, les Évènements et les Infos-trafic.

Tous les XML suivants sont utilisés dans l'application T2C en version `2.5`.

## Endpoints

| Endpoints                                                                                                                           | Description                                                                                             |
| :---------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------ |
| [alerte.xml](/WinDev/T2C_XML/alerte.md)                              | Message qui apparait au premier plan lors du lancement de l'application.                                |
| [breves.xml](/WinDev/T2C_XML/breves.md)                              | Informations affichées dans l'onglet "Brèves" et le bandeau déroulant de l’accueil dans l'appli.        |
| [evenements.xml](/WinDev/T2C_XML/evenements.md)                      | Dernières actualités T2C affichées dans l'onglet "Actualités" et "Accueil" de l’application.            |
| [infos-trafic.xml](/WinDev/T2C_XML/infos-trafic.md)                  | Obtenir les derniers incidents et autres informations.                                                  |
